# Icons

- The Activity Bar container uses [media/stemlink.svg](../media/stemlink.svg), a monochrome SVG rendered by VS Code as a theme-colored icon.
- The Marketplace icon is [media/icon.png](../media/icon.png).
- Contributed actions use VS Code codicons declared in [package.json](../package.json). Fleeting and Notes creation use `$(add)`; promotion uses `$(arrow-right)`.
- Vault rows use native selection rather than a checkmark icon. Missing reference targets use the `warning` codicon.

Keep Activity Bar artwork legible in VS Code's icon slot and verify placement and theme behavior in the host when changing it.
