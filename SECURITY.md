# Security Policy

Stemlink is a local Markdown vault extension. It does not make extension-owned network or provider calls, collect telemetry, or store vault data in a database.

Do not report vulnerabilities in public issues. Use [GitHub private vulnerability reporting](https://github.com/dmundt/stemlink/security/advisories/new) to report security concerns. Include affected versions, impact, and concise reproduction steps; do not attach private vault content or credentials.

Security updates are handled through GitHub Dependabot alerts and update pull requests.
