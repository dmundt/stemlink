# Notes instructions

- Keep permanent notes in {{notes}}, one idea per note.
- Permanent-note filenames are stable timestamped IDs. Do not rename them; link with full filename stems.
- Write YAML tags as a single-line list such as `tags: [notes, zk, bug]`, not a block list.
- Treat any legacy underscore-prefixed Markdown files here as templates, not notes, and preserve them unless asked to change them.
