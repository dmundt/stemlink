Idea: Support a MCP server in Stemlink extension to provide possible AI suport for AI-assisted note-taking workflows.

The MCP (Model Context Protocol) server would expose vault operations as tools that AI assistants can call, enabling capabilities such as:

- Searching and retrieving notes by keyword, tag, or stem
- Creating new captures in the inbox
- Promoting captures to permanent notes
- Listing backlinks and outgoing references for a given note
- Reading note content and front matter metadata

This would allow AI agents (e.g. GitHub Copilot, Claude, or any MCP-compatible client) to interact with the Stemlink vault programmatically, without requiring the user to manually copy-paste note content into a chat window.
